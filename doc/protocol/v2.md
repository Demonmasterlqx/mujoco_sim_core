# Protocol V2.0

Protocol V2 is the repository's only wire contract. Messages use protobuf package `mujoco_sim.v2`; registry and topics contain `mujoco_sim.v2` or `mujoco_sim/v2`. Every request and payload must report exactly major 2, minor 0. There is no version negotiation or downgrade path.

Controller and Observer identities share `adapter_id` and the Adapter lifecycle. Status contains only `ServerStatus.adapters`. Controller commits and both roles' heartbeats use the unified Adapter messages.

Registration returns the full `ResourceLayout`. A Tick carries only the corresponding 16-byte hash. The protocol library produces that hash from a length-prefixed, explicitly endian-defined canonical encoding using FNV-1a 128. SDK clients treat a malformed or different hash as a terminal session protocol error.

Endpoint identifiers match `^[A-Za-z0-9][A-Za-z0-9_-]{0,63}$`. Configuration and SDK validate before creating transport objects; endpoints validate at the wire boundary; Core validates Adapter identity again.

Old V1 schemas, endpoints, lifecycle methods, headers, and binaries are unsupported and absent.
